Repository

Een token in de browser is leesbaar voor iedereen die aan dit toestel kan. Gebruik een fine-grained token dat alleen déze repository mag, alleen inhoud en pull requests, met een korte vervaldatum. Niet doen op een gedeelde computer.

Bestand uploaden

Het bestand komt op een nieuwe branch en wordt een pull request. De workflows zetten het om en tonen het verschillenrapport en een preview. Publiceren blijft jouw klik.
